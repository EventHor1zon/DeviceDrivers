# Peripheral Manager

My take on the issue of enumeration in RTOS embedded devices. Device creates the peripheral manager 
then registers peripheral devices (sensors, actuators, displays etc), which have a template exposing 
their parameters. This device->{peripherals}->{{parameters}} tree allows for a convenient core to connect a variety of interfaces
